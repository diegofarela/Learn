Searching

Algorithms linear vs binary · sorted array · O(log n) comps 0

Searching asks: is a target in this collection, and where? On an unsorted array you scan left to right— O(n) linear search. Once the array is sorted, binary search halves the remaining range each probe— O(log n). Compare the growth shapes on Big-O. For patterns inside text, see string algorithms.

Linear vs binary

        

          Linear search checks index 0, then 1, and so
          on until it finds the target or runs out of cells. Binary search needs
          a sorted array: compare the midpoint, discard the half that cannot
          hold the target, and repeat. Same question, very different
          growth
          once n is large.
