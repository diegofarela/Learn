Depth-first search

Algorithms go deep · LIFO frontier · O(V + E) visited 0/7

Depth-first search (DFS) walks a graph by going as far as possible along one branch before backtracking. The frontier of pending nodes is a stack — last pushed, first expanded. Recursive DFS uses the call stack the same way (see recursion). Same graph family as breadth-first search, opposite expansion order.

When this is useful

  • Exploring all paths in a maze game, or walking every file under a project root.
  • Detecting cycles in package dependencies before npm/yarn install blows up.
  • Topological-style deep walks of nested UI component trees.

The LIFO frontier

        

          Expanding a node pushes its unseen neighbors onto the
          top of the stack. The next expansion always pops that top—so
          you keep following the newest branch until it runs out, then
          backtrack. An explicit
          stack
          makes that visible; a recursive function does the same via the
          call stack
          and
          recursion
          (each deeper call is another push).
