Arrays

Data structures contiguous · index access · O(1) access len 4 · cap 6

An array packs elements into contiguous memory slots. Given a base address and an index, the machine jumps straight to that cell— O(1) random access. That speed is why arrays back stacks, strings, and most “lists” you meet in practice. More on addresses: memory & pointers.

Contiguous memory

        

          Elements sit back-to-back. Address of index
          i is
          base + i × sizeof(element)—no chasing pointers. Cache
          lines love this layout; locality is why array scans feel cheap.
        


        
Indexing

        

          An index is just an offset. Valid range is
          0 … len − 1. Out of bounds is undefined in raw C—the
          demo aborts with a bounds check so you can see the guard fire.
        


        
Fixed vs dynamic

        

          A fixed array has a compile-time capacity. A dynamic array (vector,
          ArrayList, JS Array, growable buffer) is
          still one contiguous block—not a chain of nodes.
          It tracks both how many elements are live (length) and
          how many slots are reserved (capacity), with
          capacity ≥ length.

              append; old block becomes unused (GC / free)
            occasional

          So you are writing into reserved space—or moving the whole array to a
          larger slot when you run out—not “chaining to the next node” like a

          O(1). See also
