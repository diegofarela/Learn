Endianness & alignment

Architecture byte order · padding · structs LE

Endianness is the order of bytes in a multi-byte word; alignment inserts padding so fields sit on natural boundaries. Both matter for memory layouts, network byte order (big-endian), and float bit patterns on the wire.
