Combinatorics

Discrete math counting · n choose k · permutations C(8,3) = 56

Combinatorics counts arrangements without listing them. Binomial coefficients C(n,k) answer “how many subsets of size k?”—central to probability, balls & bins, and set theory. Counting is not the same as expectation (averaging over randomness), though they often combine.

When this is useful

  • Counting password spaces, A/B test cohorts, or seat combinations for pricing.
  • Estimating how many bracket/tournament outcomes a sports app must show.
  • Capacity planning: number of possible API key formats or SKU variants.

Permutations vs combinations

        

          Order matters for permutations (P(n,k) = n!/(n−k)!).
          Combinations ignore order—same k-subset counted once. Always ask:
          does rearranging change the outcome?
        


        
Binomial theorem

        

          (x+y)n = Σ C(n,k) xn−k yk.
          The coefficients are exactly the choose numbers you’re sliding.
