Logical clocks

Distributed Lamport · happens-before · send/recv C 0

Wall clocks drift, so distributed systems use logical clocks. A Lamport clock ticks on local events and on message send/receive so happens-before implies a smaller timestamp—useful beside consistency models and processes that exchange messages over TCP/UDP.
