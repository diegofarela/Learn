Instruction cycle

Architecture fetch · decode · execute · writeback phase fetch

The CPU repeatedly fetches an instruction, decodes it, executes it, then writes back results. Overlap those stages and you get pipelining—and the same idea of stepping work shows up in OS process state machines.
