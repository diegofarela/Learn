Randomized algorithms

Algorithms Las Vegas · Monte Carlo · pivots pivots 0

Randomized algorithms flip coins inside the code. Las Vegas always correct, runtime random (randomized quicksort); Monte Carlo may err with small probability (some fingerprinting). Analysis uses expectation and concentration.

When this is useful

  • A/B test assignment, shuffle playlists, or load-balance with random peer pick.
  • Quickselect-style “approximate top results” when exact order is too expensive.
  • Bloom filters and sketching for huge analytics where a little error is OK.

Why randomize?

        

          Foil worst-case inputs, simplify algorithms, and get good
          expected bounds. Hashing with random functions is the same
          spirit as
          hash tables.
        

        
Analysis habit

        

          Indicator variables + linearity of expectation beat expanding the full
          joint. High-probability claims need concentration inequalities.
