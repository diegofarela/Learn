Linked lists

Data structures nodes · next pointers · O(1) head ops nodes 3

A linked list is a chain of nodes. Each node holds a value and a next pointer to its neighbor. Order lives in the links—not in contiguous addresses—so you can splice at the head in constant time, but finding the k-th item costs a walk.

Nodes and pointers

        

          A node is a small record: payload plus a link. The list itself is just
          a head pointer (and sometimes a tail). The
          last node’s next is NULL—the terminator.
        


        
Versus arrays

        

          An
          array gives
          O(1)
          index access and great cache locality, but inserting in the middle
          shifts everyone. A linked list flips that tradeoff: splice by rewiring
          a few pointers, but reaching index i walks
          i links—
          O(n)
          access.
