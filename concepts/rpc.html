RPC

Networks stub · skeleton · RPC step 0/5

RPC makes a remote call look local: a client stub marshals arguments, the network carries the message, and a server skeleton unmarshals and runs the real procedure. Contrast resource-oriented REST APIs (verbs on URLs) and the bytes underneath via HTTP or sockets.

When this is useful

  • gRPC/Twirp-style service-to-service calls inside a microservice backend.
  • Mobile apps calling typed backend methods instead of hand-rolled JSON.
  • Internal admin tools that invoke remote procedures with codegen stubs.
