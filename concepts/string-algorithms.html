String algorithms

Algorithms pattern · text · mismatch step 0

String matching asks where a short pattern sits inside a longer text. The naive scan aligns the pattern at each offset and compares character by character until a mismatch or a full hit. Related idea: searching on arrays; smarter scanners (KMP, Boyer–Moore) skip using mismatch info.
