Context-free grammars

Theory productions · derivation · parse tree step 0/0

A context-free grammar (CFG) rewrites a nonterminal no matter what surrounds it. Derivations build nested structure — the same idea a parser turns into an AST. Regular languages need only finite automata / regex; CFGs sit one level higher (balanced nesting).

When this is useful

  • Parsing nested languages: JSON-ish configs, arithmetic, or a tiny query DSL.
  • Understanding why some nested constructs need real parsers, not regex.
  • Building formatters and linters that respect grammar structure.
