Finite automata

Theory states · alphabet · accept / reject char 0/0

A deterministic finite automaton (DFA) reads one symbol at a time and moves between a finite set of states. If it ends in an accepting state, the string is in the language. Related: regular expressions describe the same class of languages, and compilers use automata-like scanners in the lexer.
