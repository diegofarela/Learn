Recurrences & Master theorem

Algorithms T(n)=aT(n/b)+f(n) · cases case 2

Many divide & conquer algorithms satisfy T(n) = a T(n/b) + f(n). The Master theorem compares f(n) to nlogb a and reads off Θ growth—core homework fluency for rigorous algorithms coursework.

When this is useful

  • Estimating runtime of recursive features (merge sort, tree walks) before you ship.
  • Interview/design docs that turn “T(n)=2T(n/2)+n” into Big-O you can defend.
  • Choosing between recursive splits when building a parallel processing pipeline.

Three cases (intuition)

        

          Let ccrit = logb a. If f is polynomially
          smaller than nccrit, leaves dominate (case 1). If
          they match up to logs, cost is Θ(nccrit log n)
          (case 2). If f is larger and regular, root work dominates (case 3).
        

        
When Master fails

        

          Non-constant a,b, uneven splits, or f that sits between cases need a
          recursion tree or Akra–Bazzi. Still start by writing the recurrence
          from the code.
