Shortest paths

Algorithms Dijkstra · nonnegative · settled settled 0/6

On an unweighted graph, BFS already gives fewest edges. With positive edge weights, Dijkstra repeatedly settles the unsettled node with the smallest tentative distance, then relaxes its neighbors—often with a binary heap as the priority queue (the tree structure—not memory-heap allocation).

Settle the closest

        

          Start with dist[source] = 0 and ∞ elsewhere. While unsettled nodes
          remain, pick the one with smallest tentative distance, mark it
          settled (final), then for each neighbor try
          dist[u] + w(u,v). If that improves dist[v], update it.
          Nonnegative weights guarantee the greedy pick is forever correct.
