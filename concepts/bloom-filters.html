Bloom filters

Data structures bit array · false positives bits set 0

A Bloom filter is a compact probabilistic set: add hashes bits into an array. Query answers definitely not or maybe — never a false negative, but possible false positives. Related: hash tables and sets.

When this is useful

  • A CDN or browser check: “have we probably seen this URL?” before a heavy disk lookup.
  • A signup service that cheaply rejects usernames that almost certainly already exist.
  • Skip it when a false “maybe yes” is unacceptable—use an exact database unique index.

Maybe vs no

        

          If any hashed bit is 0, the item was never added. If all are 1, it
          might have been — collisions can create false positives. There
          are no false negatives (unless you incorrectly clear bits).
