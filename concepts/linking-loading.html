Linking & loading

Systems .o → exe · relocate stage objects

Compilers emit object files with unresolved symbols. The linker resolves them into one executable; the loader maps segments (.text, .data, …) into a process. Related: compilers and virtual memory.

When this is useful

  • Why changing a shared library can break an app at load time.
  • Understanding dynamic linking, DLLs/so files, and plugin loading.
  • Debugging “symbol not found” after a mobile or desktop release.
