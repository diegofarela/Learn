File systems

Systems directories · inode · blocks inode —

A file system maps names to bytes on disk. Directories store name → inode number; each inode holds metadata and pointers to data blocks (disk blocks—not virtual-memory pages). Related: OS processes (open file tables).

When this is useful

  • Saving documents, photos, and app data with paths, permissions, and directories.
  • Building a backup tool that walks directories efficiently.
  • Understanding why “delete” isn’t always immediate reclaim on some volumes.

          indirect) locate the file’s bytes on disk—not the path string itself.
