Garbage collection

Systems roots · mark/sweep · heap live 0

Garbage collection reclaims heap objects that are no longer reachable from roots (globals, stack). Mark-and-sweep marks everything reachable, then frees the rest. Related: memory & pointers and OS processes (address spaces).

Mark then sweep

        

          Start from roots and follow references, marking every visited object.
          Anything still unmarked is garbage and can be swept. Reference counting
          is an alternative that frees when a count hits zero (cycles need extra
          care).
