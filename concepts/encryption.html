Encryption

Security plaintext → ciphertext · key · symmetric shift 3

Encryption turns readable plaintext into unreadable ciphertext using a key; decryption reverses it. Unlike encoding (Base64, UTF-8), encryption hides data—you need the key. This page uses a toy Caesar cipher so you can see the steps—real systems use AES, ChaCha, RSA, and friends. Contrast cryptographic hashing (one-way fingerprints, no key to “unlock”). On the web, HTTP over TLS is HTTPS.

Symmetric vs public-key

        

          Symmetric schemes (AES) use one shared secret.
          Public-key schemes (RSA, ECC) use a key pair: encrypt
          with the public key, decrypt with the private. Caesar is a tiny
          symmetric shift—easy to break by trying 25 keys.
