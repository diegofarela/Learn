Memory & pointers

Foundations address · dereference · & / * p → 0x1008

A pointer is a variable that stores a memory address—not the value itself. &x takes the address of x; *p follows that address to read or write. Names often live in small call-stack slots; bigger or longer-lived objects live on the heap—both are just addressable memory (see Stack vs heap below).

Address vs value

        

          Every variable lives somewhere. The address is where; the
          contents are what. A pointer variable’s value is an
          address. That indirection is why
          arrays
          decay to pointers and why linked structures can grow without moving
          callers.
