Memory & pointers

Foundations address · dereference · & / * p → 0x1008

A pointer is a variable that stores a memory address—not the value itself. &x takes the address of x; *p follows that address to read or write. Contrast the call stack (automatic locals) with the heap (dynamic allocations)—both are just addressable slots.

Address vs value

        

          Every variable lives somewhere. The address is where; the
          contents are what. A pointer variable’s value is an
          address. That indirection is why
          arrays
          decay to pointers and why linked structures can grow without moving
          callers.

Stack vs heap

        

          Locals often live on the
          call stack
          (or a data-structure
          stack
          in spirit): automatic lifetime, fixed frames. Heap memory is allocated
          at runtime and reached only through pointers—flexible size, manual or
          GC cleanup. Same address idea either way.
