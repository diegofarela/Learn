Binary search trees

Data structures ordered keys · left < node < right · search / insert size 5 · height 2

A binary search tree (BST) is a binary tree with an ordering rule: every key in the left subtree is less than the node, and every key on the right is greater. That invariant turns search and insert into a walk down one path—often written with recursion.

The BST property

        

          For every node, keys to the left are smaller and keys to the right are
          larger. Inorder traversal of a BST therefore yields sorted order. Shape
          still matters: a balanced tree is short; a sorted insert sequence can
          collapse into a skinny chain of height n − 1.

For mastery

          
    
            
  • 
              Invariant
              For every node: all keys in the left subtree are < the node,
              all in the right are > (in-order walk is sorted).
            
    • 
            
  • 
              When / when not
              Use as an ordered dictionary when you need predecessor/successor.
              Not for guaranteed O(log n) without
              balance,
              and not for “extremum at root” (
              heaps).
            
    • 
            
  • 
              Common failure
              Sorted inserts build a spine → O(n) search; insert/delete that
              breaks the BST property.
            
    • 
            
  • 
              Proof shape
              Search follows comparisons; correctness is induction on the BST
              invariant — see
              induction & invariants.
            
    • 
            
  • 
              Assumes
              A total order on keys and a defined policy for duplicates.
