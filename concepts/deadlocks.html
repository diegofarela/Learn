Deadlocks

Programming models circular wait · Coffman ready

A deadlock is when threads wait forever in a cycle: each holds a lock the other needs. Classic fix: acquire locks in a global order. Built on synchronization and threads.

When this is useful

  • Diagnosing two DB transactions each waiting on the other’s row lock.
  • Designing lock order conventions so checkout never wedges the store.
  • Timeouts and deadlock detection in a job queue admin panel.
