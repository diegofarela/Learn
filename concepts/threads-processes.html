Threads & processes

Programming models shared memory · isolation · stacks view threads

A process is an OS-level program instance with its own address space. A thread is a schedulable path of execution inside a process—threads share heap and globals but keep private stacks. Switch the view to compare one multi-threaded process vs two isolated processes. See OS processes, concurrency, parallelism, synchronization (why shared memory needs locks), and CPU scheduling.
