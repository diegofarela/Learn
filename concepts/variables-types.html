Variables & types

Foundations name · value · type x : number

A variable is a named slot that holds a value. The type of that value says what you can do with it—add numbers, concatenate strings, call methods. Below: mutate the object in place vs rebind the name to a new value, and a tiny type tree.

          assign; objects are shared until you rebind. Related:
