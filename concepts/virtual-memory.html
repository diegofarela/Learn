Virtual memory

Systems pages → frames · page fault mapped 3 / 6

Virtual memory gives each process a private address space of pages. The OS + MMU map those pages onto physical frames in RAM. Touch a page that isn’t mapped → a page fault; the OS loads or allocates a frame. See also caching (another hierarchy layer) and OS processes (each gets its own address space).

Address translation

        

          A virtual address splits into a page number and an
          offset. The page table maps page → frame; the MMU concatenates the
          frame with the offset to get a physical address—transparent to the
          program, which only sees virtual addresses.
        


        
Page faults

        

          If the page isn’t present (or isn’t allocated yet), hardware traps to
          the OS. The kernel may free a frame, load the page from disk (swap),
          update the page table, then restart the instruction. Costly—but it
          lets the working set exceed physical RAM.

For mastery

          
    
            
  • 
              Invariant
              Each process sees a virtual address space; VA→PA via page tables /
              TLB; a fault loads or maps a page (or signals an error).
            
    • 
            
  • 
              When / when not
              Use for isolation, large sparse spaces, and demand loading. Not
              free — TLB misses and page faults are real costs (see
              caching).
            
    • 
            
  • 
              Common failure
              Thrashing when the working set exceeds RAM; confusing virtual
              with physical addresses in
              pointers.
            
    • 
            
  • 
              Proof shape
              Translation + permission bits enforce isolation: one process
              cannot name another’s physical pages without a mapping.
            
    • 
            
  • 
              Assumes
              MMU/TLB hardware, an OS pager, and enough locality that paging
              helps more than it hurts.
