Functional programming

Programming models map · filter · reduce · pure result —

Functional programming builds programs by composing functions. Prefer pure functions (same inputs → same output, no side effects) and immutable data. Contrast with OOP, where behavior often lives on mutable objects.

Purity

        

          A pure function’s result depends only on its arguments. Flip
          Impure to log to a shared counter—same math, but now the call
          has a side effect.
        


        
Immutability

        

          Prefer copying and transforming over mutating. Copy + change
          leaves the original list intact; Mutate in place rewrites
          it—harder to reason about when data is shared.
