Pipelining

Architecture IF · ID · EX · MEM · WB · hazards cycle 0

Pipelining overlaps stages of the instruction cycle so several instructions are in flight at once. Data hazards may stall or be fixed by forwarding—similar tension to waiting vs overlapping work in CPU scheduling.

When this is useful

  • Why CPUs (and some GPUs/network stacks) overlap work for throughput.
  • Designing multi-stage media pipelines: decode → filter → encode.
  • Diagnosing hazards/stalls when performance counters look weird.
