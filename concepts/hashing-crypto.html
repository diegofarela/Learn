Cryptographic hashing

Security one-way · fixed digest · avalanche SHA-256

A cryptographic hash maps arbitrary input to a fixed-size digest. It is designed to be one-way and collision-resistant—not the same as a hash table hash, which only needs to scatter keys into buckets. Pair with encryption (reversible with a key) for the full crypto basics picture.

Not a hash table

        

          Table hashes are fast indexers; crypto hashes are
          fingerprints. You cannot usefully “invert” SHA-256 to recover
          the message, and finding two inputs with the same digest should be
          infeasible. Password stores and integrity checks rely on that.
        


        
Avalanche

        

          Change one bit of input and roughly half the output bits flip. The demo
          shows how unrelated digests look after a one-character edit.
