Induction & invariants

Discrete math base case · inductive step · invariant n = 5

Induction proves a claim for every natural number by checking a base case, then showing that if it holds for k it holds for k+1. The same idea powers loop invariants in algorithms—and pairs with counting in combinatorics and structure in sets, relations & functions.

Base case

        

          Prove P(1) (or P(0)) directly. For
          Σi=1n i = n(n+1)/2, the left side
          at n=1 is 1 and the right side is 1 — done. Without a true base, the
          chain never starts.
        


        
Inductive step

        

          Assume P(k) (the
          induction hypothesis). Add (k+1) to both sides and algebra shows P(k+1). Together with
          the base, P(n) holds for every n ≥ 1.
        


        
Invariants in code

        

          A loop invariant is a claim true before the loop and after each
          iteration—induction in programming clothes. When the loop exits, the
          invariant plus the exit condition give the postcondition you need.
