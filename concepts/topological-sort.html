Topological sort

Algorithms DAG · Kahn · indegree order 0/6

A topological order of a DAG (graph with directed edges and no cycles) lists every node before the nodes that depend on it. Kahn’s algorithm repeatedly peels off indegree-zero nodes — the same frontier idea as BFS, but driven by remaining prerequisites.

When this is useful

  • Ordering course prerequisites, CI pipeline stages, or spreadsheet formula dependencies.
  • Package installers that must build libraries before apps that depend on them.
  • Task managers that refuse circular “blocked by” links.
