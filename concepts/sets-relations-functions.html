Sets, relations & functions

Discrete math membership · ordered pairs · function mode relation

Sets collect distinct elements. A relation is a set of ordered pairs; a function is a relation where every domain element has exactly one image. That language underpins set ADTs, maps, and graph theory.

Sets

        

          Membership is yes/no. Union, intersection, and difference build new
          sets from old ones—the same algebra you see in the data-structure
          Sets lab.
        


        
Relations

        

          A binary relation R ⊆ X × Y is any collection of pairs (x, y). No
          uniqueness rule: one x may relate to several y, or to none.
        


        
Functions

        

          f: X → Y requires every x ∈ X to have
          exactly one y with (x, y) ∈ f. That is why hash maps and
          mathematical functions feel the same: key → single value.
