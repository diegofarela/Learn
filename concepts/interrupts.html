Interrupts

Systems IRQ · ISR · return phase idle

An interrupt lets hardware pause the CPU when a device needs attention—disk done, network packet, timer tick. The CPU saves state, runs an ISR, then returns to the interrupted work. Contrast system calls (software-requested) and CPU scheduling (timer IRQs enable preemption).
