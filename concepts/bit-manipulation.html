Bit manipulation

Algorithms AND · OR · XOR · NOT · shifts res 0x2A

Bitwise ops apply Boolean logic to every bit in parallel. Pick an operation, tweak the operands, and watch the result row light up. Related place-value thinking lives in number systems.

When this is useful

  • Compact permission bitmasks, chess move boards, or GPU-friendly flags in a game.
  • Fast “is power of two?” checks and bitsets for calendar free/busy slots.
  • Networking code that packs protocol headers into tight binary frames.
