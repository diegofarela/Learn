Union-find

Data structures disjoint sets · union by rank · find root sets 4 · n 6

Union-find (a disjoint-set structure) tracks a partition of elements into non-overlapping groups. Find returns the representative (root) of an element’s set; Union merges two sets. That is the engine behind connected components and Kruskal’s MST on graphs.

When this is useful

  • Merging friend circles or “accounts that are the same person” after linking emails.
  • Kruskal-style network design: connect cities/cables without creating redundant loops.
  • Offline “are these pixels in the same blob?” in an image or map flood-fill pipeline.

Parent pointers

        

          Each element stores a parent. Roots are their own
          parent. Find climbs to the root; Union links one root under the
          other. This demo uses union by rank (attach the shallower
          tree under the taller) so trees stay short. Path compression is
          omitted so you can see the parent chain clearly.
        


        
Operations

        
    
          
  • 
            find(x)
            walk parents to the root
            ≈ O(α(n))*
          
    • 
          
  • 
            union(a, b)
            link roots if different sets
            ≈ O(α(n))*
          
    • 
          
  • 
            same(a, b)
            find(a) == find(b)
            ≈ O(α(n))*
          
    • 
        

        

          *With union-by-rank + path compression, amortized cost is the inverse
          Ackermann function α(n)—effectively constant.
