Balls & bins

Probability for CS collisions · birthday paradox balls 10

Throw m balls independently into n bins. Collisions appear surprisingly early—the birthday paradox. Same math as hash table load and bloom filters; pair with expectation and probability basics.

When this is useful

  • Load balancing: throwing requests into random servers and expecting imbalance.
  • Hashing and caching occupancy—why one hot key gets hammered.
  • Capacity intuition for sharded databases and lottery-style assignments.

Collisions

        

          With m ≈ √n balls, a collision becomes likely. For n = 365, m = 23
          already exceeds 50%—counterintuitive until you count pairs with
          C(m,2).
        


        
Expected load

        

          Each bin’s load is Binomial(m, 1/n); expected load is m/n. Max load is
          ~ log n / log log n with high probability when m = n—classic hashing
          folklore.
