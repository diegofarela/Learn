Backtracking

Algorithms try · fail · undo · prune queens 0/4

Backtracking builds a solution one choice at a time. If a partial candidate cannot work, it undoes the last choice and tries another—exactly the try / fail / undo pattern. It is recursion (and DFS-shaped search) with early pruning. The classic demo: place four queens so none attack.

Try, fail, undo

        

          For each row, try every column. If the square is safe (no shared
          column or diagonal with earlier queens), place and recurse to the next
          row. If every column fails—or a later row dead-ends—remove the queen
          and try the next column. That undo is the “backtrack.”
