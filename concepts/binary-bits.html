Binary & bits

Foundations base-2 · places · bit dec 42 · hex 0x2A

Computers count in binary: only 0 and 1. Each digit is a bit; its place is a power of two. Flip bits below and watch decimal and hex update—then connect the same on/off idea to Boolean logic.

When this is useful

  • Building a permissions system where each flag is a bit in one integer (read/write/admin).
  • Debugging why a color, IP, or packed header looks wrong in a hex dump.
  • Writing low-level code that packs booleans into bytes to save space in a mobile or IoT payload.

Only two symbols

        

          Decimal uses ten digits. Binary uses two: 0 (off) and
          1 (on). That maps cleanly to switches, voltages, and
          magnetic domains—why machines speak binary natively. Group bits into
          bytes (8), words, and so on when you need larger numbers.

Shifts

        

          Shift left multiplies by two (when nothing falls off the end); shift
          right divides by two for unsigned values. Bits that leave the byte are
          gone—overflow and underflow in miniature. Combine shifts with masks in
          bit manipulation.
