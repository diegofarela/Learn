Memory consistency

Systems SC vs weak · SC model SC

A memory consistency model says which orders of loads and stores other cores are allowed to observe. Under sequential consistency, there is one global interleaving. Weaker models (store buffers, reordering) allow extra outcomes. Related: synchronization, concurrency, and memory & pointers.

Two cores · litmus test

Both cores write then read the other’s flag · see allowed (r1, r2)

Pick a model, then run. Under SC, (0,0) is impossible.
