Stack

Data structures LIFO · push / pop / peek · O(1) size 3

A stack is a collection you only touch at the top. Push adds, pop removes, peek looks without removing. Last in is first out—like a pile of plates, or the call stack your program uses for nested function calls.

The rule

        

          Access is restricted to one end. That is the whole abstract data type:
          you never dig into the middle. Under the hood a stack is often an
          array
          (grow an index) or a
          linked list
          (insert at the head)—same behavior, different guts. The demo on the
          right is the array version.

Where stacks show up

        
    
          
  • 
            Undo — each edit is pushed; undo pops the last change
          
    • 
          
  • 
            Call stack
            — every function call pushes a frame; return pops it
          
    • 
          
  • 
            Depth-first search
            — explore deep with an explicit stack (or recursion’s implicit one)
          
    • 
          
  • 
            Expression parsing — matching brackets, postfix eval
          
    • 
          
  • 
            Browser history (back) — pages stacked as you navigate
