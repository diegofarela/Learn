Binary trees

Data structures root · left / right · ≤ 2 children size 3 · height 1

A binary tree is a tree where every node has at most two children: a left child and a right child. One node is the root; nodes with no children are leaves. Shape alone is the idea here—ordering (search trees) and priority (heaps) come later.

Root and leaves

        

          The root is the top: every path into the tree starts
          there. A leaf has no children. Internal nodes sit in
          between. Selecting a node in the demo marks which parent will receive
          the next left or right child.
        


        
Height vs size

        

          Size is how many nodes exist. Height
          is the longest root-to-leaf path (in edges). A skinny chain of
          n nodes has height n − 1; a fuller tree of the same
          size is much shorter. Algorithms that walk down from the root care
          about height, not just size.
