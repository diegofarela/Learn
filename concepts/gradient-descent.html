Gradient descent

ML foundations loss · step size · gradient x —

Gradient descent minimizes a loss by repeatedly stepping opposite the slope. Tune the learning rate below—too large and you overshoot; too small and you crawl. Local search along a slope, not discrete backtracking over choices. Uses vector / calculus ideas; interacts with bias–variance when fitting models.
