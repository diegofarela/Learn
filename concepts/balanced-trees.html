Balanced trees

Data structures AVL · height balance · rotations height 0 · next 10

A plain binary search tree can skew into a linked list if you insert sorted keys. A self-balancing BST restores a height invariant after updates. This lab is an AVL tree: for every node, the heights of the left and right subtrees differ by at most one. Violations trigger a rotation.

Height balance

        

          The balance factor of a node is
          height(left) − height(right). AVL allows −1, 0, or +1. After insert,
          if any ancestor hits ±2, a single or double rotation rewires parent
          and child links so the BST order stays and heights shrink back into
          range. Result: height stays O(log n), so search stays fast.
