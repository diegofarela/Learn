Version control

Software commits · branch · DAG focus A

Version control stores snapshots ( commits) linked to parents—a DAG. Branches are movable labels; a merge commit joins histories. This is collaboration history, not a database WAL or backup. Pair with testing before integrating.

When this is useful

  • Daily git workflows: branches, PRs, bisecting a bug that landed last Tuesday.
  • Coordinating a team on one codebase without overwriting each other.
  • Release tags and hotfixes for a production mobile/web app.
