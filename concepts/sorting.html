Sorting

Algorithms rearrange into order · compare by growth · O(n log n) swaps 0

Sorting puts elements into a chosen order— usually ascending numbers. Simple swaps (bubble, insertion) are easy to see but grow O(n²) in the worst case. Divide-and-conquer merge sort stays O(n log n). Compare the curves on Big-O; once sorted, you can search in logarithmic time.

When this is useful

  • Ordering a music library by artist, or an e-commerce catalog by price.
  • Preparing data so binary search and merge steps stay fast in reports.
  • Choosing stable vs unstable sort when “ties keep original upload order” matters in a gallery.
