Maps / dictionaries

Data structures key → value · associative array n 3

A map (dictionary, associative array) stores key → value pairs. Each key appears at most once; put overwrites, get looks up, delete unbinds. The ADT is what you use; a hash table is the usual engine underneath. A set is the same idea with only keys—no payload values.

ADT vs hash table

        

          The map is the contract: put, get, delete by key.
          A
          hash table
          is one implementation that delivers average
          O(1) lookups. Trees can implement ordered maps; the ADT
          stays the same.
        


        
Keys are unique

        

          Putting the same key twice replaces the value—it does not create a
          second entry. That uniqueness is shared with
          sets, which store only
          the keys.
