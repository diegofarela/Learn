OS processes

Systems PCB · states · isolation state new

A process is a running program plus its resources: address space, open files, and a PCB. The kernel moves it through new → ready → running → waiting → terminated. Contrast threads (share memory inside one process) and CPU scheduling (who leaves ready for running).
