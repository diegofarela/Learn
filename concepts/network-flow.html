Network flow

Algorithms residual · augment · max-flow flow 0

In a flow network, each edge has a capacity. Max flow pushes as much as possible from source s to sink t without exceeding capacities. Ford–Fulkerson repeatedly finds an augmenting path in the residual graph; Edmonds–Karp picks a shortest path via BFS. Related graph ideas: graphs and topological sort.
