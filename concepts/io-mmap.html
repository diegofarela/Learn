I/O & memory mapping

Systems buffer I/O · mmap path buffer

Programs move file bytes with buffered I/O (read/write into a user buffer) or with mmap, which maps file pages into the address space so loads/stores touch the file via the page cache. Related: virtual memory, system calls, and file systems.
